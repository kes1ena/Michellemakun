02 / About the studio

Rooted in place.
Made to be remembered.

michellemakun Studio is a collection of art inspired by the soul of African cities—quiet moments, familiar faces, fleeting encounters, and places that linger in memory long after you’ve left. Each piece is an invitation to pause, remember, and see the beauty in the everyday.
